# Soniboost

**Soniboost** — Android-приложение для более разборчивого прослушивания речи через наушники с микрофоном. Приложение захватывает звук с микрофона, обрабатывает его в реальном времени и воспроизводит в наушники, чтобы речь собеседника и окружающий разговор было проще разобрать.

> ⚠️ **Немедицинский статус.** Soniboost — потребительский прототип для более разборчивого прослушивания речи через наушники. Это **не медицинское изделие и не медицинская услуга**. Медицинская экспертиза и клиническая валидация **не проводились и не планируются**: у проекта нет ресурсов на такую экспертизу. Приложение не диагностирует и не лечит потерю слуха и не заменяет слуховой аппарат или консультацию специалиста.

---

## Возможности

- 🎙️ **Усиление речи в реальном времени** — обработка сигнала с микрофона и вывод в наушники.
- 🗣️ **Адаптивный речевой буст** — анализ спектра и динамический подъём формантных областей голоса.
- 🎚️ **Графический эквалайзер** — ручная настройка АЧХ по полосам.
- 🎛️ **Параметрический эквалайзер** — точная настройка частоты, добротности и усиления.
- 🔄 **Frequency lowering** — компрессия/транспозиция высокочастотных компонентов в воспринимаемую область.
- 🛡️ **Always-on лимитер** — защита от чрезмерного усиления и опасных уровней громкости.
- 💾 **Шаблоны настроек** — готовые пресеты и сохранение собственных конфигураций.
- 🔋 **Профили энергопотребления** — автоматическое снижение нагрузки при низком заряде или нагреве.
- 📱 **Проверка возможностей устройства** — выбор безопасных параметров обработки под конкретный смартфон.
- 🔔 **Фоновая работа** — обработка продолжается при выключенном экране через foreground service.
- ☎️ **Обработка звонков** — приостановка обработки микрофона и переключение аудиомаршрута во время звонка.

## Шаблоны по умолчанию

| Шаблон | Назначение |
|---|---|
| **Speech Boost — Mild** | Мягкий фиксированный подъём речевых частот |
| **Speech Boost — Strong** | Более агрессивный подъём разборчивости речи |
| **Adaptive Speech Boost** | Динамическое выделение формант голоса |
| **Graphic EQ Boost** | Общее усиление с графическим эквалайзером |
| **Parametric Profile** | Параметрическая кривая для ручной настройки |
| **Frequency Lowering — Moderate** | Умеренный перенос высоких частот |
| **Frequency Lowering — Strong** | Более агрессивный frequency lowering |

Пользователь может создавать, редактировать, экспортировать и импортировать собственные шаблоны.

## Архитектура аудиоконвейера

```text
Микрофон / AudioRecord
        ↓
Pre-processing: DC removal, pre-gain
        ↓
Pre-EQ (опционально)
        ↓
Frequency Lowering (опционально)
        ↓
Adaptive Speech Boost / Formant Enhancement (опционально)
        ↓
Post-EQ: графический или параметрический
        ↓
Многополосная компрессия
        ↓
Лимитер (обязателен)
        ↓
AudioTrack / Oboe output → наушники
```

Ключевые принципы:

- **Низкая задержка:** Oboe с `LowLatency` / `Exclusive`, fallback на `AudioTrack`.
- **Безопасность:** лимитер всегда последний в цепочке и не отключается пользователем.
- **Гибкость:** модули можно включать/выключать, порядок обработки конфигурируем.
- **Энергоэффективность:** профили Max Quality / Balanced / Power Saver.

## Технологии

- **Язык:** Kotlin + C++/NDK для аудиообработки.
- **Минимальная версия Android:** API 28 (Android 9).
- **Аудио I/O:** Oboe, `AudioRecord` / `AudioTrack`.
- **Обработка:** `android.media.audiofx.DynamicsProcessing`, собственные DSP-модули для frequency lowering.
- **Хранение настроек:** DataStore / Room.
- **Фоновая работа:** Foreground Service с типом `microphone` / `phoneCall`.

## Безопасность и ограничения

- Приложение **не является медицинским изделием и не является медицинской услугой**. Оно не предназначено для диагностики, лечения или подбора слуховой коррекции.
- Медицинская экспертиза не проводилась и не планируется. Настройки — это пользовательские пресеты обработки звука, а не клинически проверенные профили.
- Лимитер ограничивает максимальный выходной уровень, но **не гарантирует безопасность при любых наушниках** — громкость зависит от чувствительности наушников.
- Frequency lowering и адаптивный буст могут улучшать разборчивость, но **искажать естественность звука**.
- В шумной обстановке приложение без направленного микрофона не может гарантированно выделить именно голос собеседника.
- Пользователям с потерей слуха рекомендуется консультация аудиолога.
